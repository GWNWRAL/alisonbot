# 07 · 打包与发布

本文面向维护者，说明 AlisonBot 的产物命名规则、发布流程与校验要点。**具体的构建脚本与内部步骤以仓库为准**：本文只描述对外可见的约定，不重复仓库中的构建实现，以免与实际脚本脱节。

## 一、版本号规则

- 采用语义化版本：`主版本.次版本.修订号`，当前为 **0.0.1**。
- 发布标签统一加 `v` 前缀：`v0.0.1`。
- 产物文件名内嵌版本号，与标签一致，便于核对。

## 二、产物清单

所有产物发布在 GitHub Releases 页面：

```text
https://github.com/GWNWRAL/alisonbot/releases
```

| 产物 | 平台 | 说明 |
| --- | --- | --- |
| `Alison-Setup-0.0.1.exe` | Windows | 安装程序；向导可选安装位置与工作区位置 |
| `Alison-Windows-便携版-0.0.1.zip` | Windows | 便携版；解压后双击 `Alison.exe` |
| `Alison-macOS-arm64-0.0.1.zip` | macOS | Apple Silicon |
| `Alison-macOS-x64-0.0.1.zip` | macOS | Intel |

命名约定：

```text
Alison-<形态>-<版本>.<扩展名>
Alison-<平台>-<架构>-<版本>.zip
```

源码方式不发独立产物，直接由仓库提供：Windows 用 `install.cmd` / `start.cmd`，macOS 用 `install-mac.sh`，均需要 Node.js 20 或更高版本。

## 三、发布前检查清单

**内容**

- [ ] 版本号在三处一致：仓库版本、标签 `v0.0.1`、产物文件名中的 `0.0.1`。
- [ ] `LICENSE` 存在且版权行为 `Copyright (c) 2026 GWNWRAL`（MIT）。
- [ ] `CHANGELOG.md` 已补充本版本条目。
- [ ] 文档中的下载链接与产物文件名逐字一致（含中文文件名 `Alison-Windows-便携版-0.0.1.zip`）。

**安全**

- [ ] 仓库与产物中**没有真实 API Key**、没有真实 QQ 号、没有真实用户昵称或群名。
- [ ] 示例配置中的凭据一律是占位符（如 `sk-你的Key`）。
- [ ] 工作区中的 `workspace/alison.yml` 不会被误打包进产物；如打包模板自带示例配置，其中的凭据字段必须为空或占位符。
- [ ] 日志、截图不含隐私信息。

**功能**

- [ ] Windows 安装程序可完成安装并启动。
- [ ] Windows 便携版解压后可直接启动。
- [ ] macOS arm64 与 x64 包分别能在对应芯片上启动。
- [ ] 启动后 <http://127.0.0.1:5140/alison> 可访问。
- [ ] 首次启动时对话引导能正常发起。

## 四、macOS 产物的可执行权限

从压缩包解压出的文件默认没有执行位，因此文档中的安装步骤包含：

```bash
chmod +x install-mac.sh "启动 Alison.command"
```

打包时请确认：

- 压缩包内的 `install-mac.sh` 与 `启动 Alison.command` 名称正确（含空格与中文）；
- 文件名中的空格不会在解压后丢失；
- 发布说明中给出的命令与实际文件名一致。

## 五、发布流程

1. 确认工作区干净，所有待发布改动已合并。
2. 更新 `CHANGELOG.md`，把「未发布」内容归入本次版本。
3. 核对版本号，生成构建产物（构建脚本详见仓库）。
4. 按第三节清单逐项自检。
5. 打标签并推送，例如：

   ```bash
   git tag v0.0.1
   git push origin v0.0.1
   ```

6. 在 GitHub Releases 创建对应标签的正式发布，上传第二节列出的全部产物。
7. 在发布说明中写明：
   - 本版本新增、变更、修复与**已知限制**；
   - 各产物的适用平台与安装方式；
   - 与上一版本的差异（首个版本可省略）。

## 六、发布说明模板

```markdown
## AlisonBot v0.0.1

微内核 + 一切皆插件，自托管聊天机器人。基于 Koishi 4.18 与 ChatLuna 1.4（第三方依赖）。

### 下载
- Windows 安装程序：Alison-Setup-0.0.1.exe
- Windows 便携版：Alison-Windows-便携版-0.0.1.zip
- macOS（Apple Silicon）：Alison-macOS-arm64-0.0.1.zip
- macOS（Intel）：Alison-macOS-x64-0.0.1.zip

### 亮点
- 微内核与一切皆插件
- 对话式首次引导：Alison 主动问出 API Key 并当场测试
- 热更新与热配置，改设置不重启
- 插件自装自修
- 多平台插件兼容（AstrBot / NoneBot2 / MaiBot 命令子集，LangBot 尽力而为）

### 已知限制
- mirai-console 插件未支持（规划中）
- 兼容桥只覆盖命令注册层，依赖完整运行时的插件不可用
- 少数改动（如 ChatLuna 预设的会话级缓存）仍需重启

完整说明见 README.md 与 docs/。
```

## 七、注意事项

- **不要发布带有个人配置的包**：构建前确认产物中不含任何本地工作区数据。
- **中文文件名要确认可用**：`Alison-Windows-便携版-0.0.1.zip` 在部分工具链中可能出现编码问题，发布后请实际下载验证一次。
- **校验和**：如需提供校验值，请按仓库约定生成并在发布说明中给出。
- **产物与文档同步**：文档中的下载链接失效是最常见的问题，发版后请打开链接核对。
