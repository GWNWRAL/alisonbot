# 03 · 首次部署与对话引导

AlisonBot 的首次部署不需要你编辑任何配置文件。没有模型凭据时，Alison 会在你第一次打开聊天后**主动开口**，用对话把配置问出来、写进去、当场验证。

本文逐步说明这套引导，并给出示例对话。示例中的 Key 一律用 `sk-你的Key` 代替，请勿把真实 Key 写进任何公开位置。

## 一、前提

1. 已完成安装（Windows 见 [01-安装-Windows.md](01-安装-Windows.md)，macOS 见 [02-安装-macOS.md](02-安装-macOS.md)）。
2. Alison 已启动。
3. 手边准备好你要用的模型服务的 API Key。

## 二、找到 Alison

任选一种方式：

| 方式 | 操作 |
| --- | --- |
| 网页 | 浏览器打开 <http://127.0.0.1:5140/alison> |
| QQ | 直接私聊她（需要已接好 QQ 平台；首次部署通常先走网页） |

## 三、为什么她会先开口

常规做法是：先去改配置文件填 Key，改完再重启。AlisonBot 把这一步改成对话：因为还没填 API Key，她会在你打开聊天时先说话，一步步问清楚。

这样做的直接好处是：

- 不需要知道配置文件在哪、字段叫什么；
- Key 是否可用**当场测试**，不必「填完再试错」；
- 平台与能力开关也在同一轮对话里定下来。

## 四、引导步骤

### 步骤 1：选择模型提供方

她先问你打算用哪家模型。可选项包括 deepseek、qwen，以及任意 **OpenAI 兼容网关**（自建网关填 `baseURL` 即可）。

### 步骤 2：提供 API Key

你把 Key 贴给她。她会把它写入 `workspace/alison.yml`。

### 步骤 3：当场测试连通

写入后立即发起一次测试调用：

- 成功：她告诉你已生效，进入下一步；
- 失败：她反馈失败原因（例如 Key 无效、余额不足、网络不通、baseURL 写错），并请你修正后重试。

### 步骤 4：选择对话平台

她问你要接哪个平台：网页、QQ，或两者都要。网页默认已经可用；QQ 需要 OneBot v11 实现（如 NapCat / LLOneBot / SnowLuma），她会引导你填连接信息。

### 步骤 5：选择要开启的能力

她会逐个问：要不要开记忆、要不要开日记、要不要开好感度。这些都记录在配置的 `features` 段。

### 步骤 6：是否安装插件

如果她想推荐某个插件，或者你有想加的能力，会在这里问你是否安装。插件的安装与启停由 Alison 自己完成，不需要你手工操作。

### 步骤 7：进入正常聊天

引导结束后就是普通对话。之后想改任何设置，都可以直接在对话里说，或去控制中心改（见 [04-控制中心与系统设置.md](04-控制中心与系统设置.md)）。

## 五、示例对话

下面是一段完整的首次部署对话示例（内容为示意，实际话术可能不同）：

```text
Alison：你好，我是 Alison。我还没拿到大模型的钥匙，
        先聊两句把它配好——你打算用哪家的模型？
你　　：deepseek
Alison：好。把 API Key 贴给我吧，我写进配置后立刻测一次连通。
你　　：sk-你的Key
Alison：正在测试……通过了 ✅ 已经生效。
        接下来想接哪个平台？网页聊天已经可用，要不要再加 QQ？
你　　：先网页吧
Alison：好。还想开哪些能力？记忆、日记、好感度，都可以现在决定。
你　　：开记忆，其它先不着急
Alison：明白。记忆已开启。
        最后问一句：要不要我顺手装一个网页搜索插件？
你　　：暂时不用
Alison：没问题，随时可以找我。那我们开始聊天吧。
```

### 连通失败时的示例

```text
Alison：我在测试时收到「鉴权失败」，看起来 Key 不对或者已经失效。
        你可以在服务商后台确认后重新贴给我，我马上再测一次。
你　　：sk-新的Key
Alison：这次通过了 ✅ 已经生效。
```

## 六、手动配置（可选）

不喜欢对话引导也可以手动改：配置文件是 `workspace/alison.yml`。下面是一份**结构示例**，具体键名与默认值以仓库中的配置定义为准：

```yaml
# workspace/alison.yml（结构示例，字段以实际版本为准）
model:
  provider: deepseek
  apiKey: sk-你的Key
  baseURL: ''

platform:
  web:
    enabled: true
    host: 127.0.0.1
    port: 5140
  qq:
    enabled: false
    protocol: onebot11

features:
  memory: true
  diary: false
  favorability: false
```

改完**不需要重启**：热更新会进程内生效。仅少数需要整体重建的改动（例如 ChatLuna 预设的会话级缓存）会提示重启，详见 [06-热更新与自治能力.md](06-热更新与自治能力.md)。

## 七、注意事项

- **不要把真实 Key 贴到公开场合**：截图、Issue、仓库里都不要出现真实 Key。
- **Key 存在本机**：写在你的 `workspace/alison.yml` 中，仅用于你配置的模型服务。
- **引导可以中断**：随时退出聊天没关系，下次打开她会接着问没问完的部分。
- **平台随时可加**：QQ 现在不接，以后在对话里说一声就行。
