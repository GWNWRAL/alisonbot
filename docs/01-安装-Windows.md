# 01 · 在 Windows 上安装 AlisonBot

本文覆盖 Windows 上的三种安装方式（安装程序、便携版、源码运行），以及启动、验证、卸载与排错。安装完成后请继续阅读 [03-首次部署与对话引导.md](03-首次部署与对话引导.md)。

## 一、环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（64 位） |
| 安装程序 / 便携版 | 无需预装 Node.js，发行包已含运行环境 |
| 源码运行 | Node.js **20 或更高版本** |
| 磁盘 | 预留足够空间，用于运行环境、依赖与 `workspace/` 数据 |

> 如果你打算用 Python 插件（AstrBot / NoneBot2 / MaiBot / LangBot），还需要本机安装 **Python 3.9 或更高版本**。

## 二、方式一：安装程序（推荐）

安装包文件名：`Alison-Setup-0.0.1.exe`

1. 双击 `Alison-Setup-0.0.1.exe`。
2. 按向导提示操作，向导中可以选择：
   - **安装位置**：程序本体所在目录；
   - **工作区位置**：`workspace/` 的存放位置，配置、插件与数据都在这里。
3. 完成安装，从开始菜单或桌面快捷方式启动 Alison。

建议把工作区放在一个有读写权限、路径中不含特殊字符的目录，例如 `D:\Alison`。工作区与程序本体分开存放的好处是：升级程序时不会动到你的配置与数据。

## 三、方式二：便携版

压缩包文件名：`Alison-Windows-便携版-0.0.1.zip`

```text
1. 解压到任意目录，例如：
   D:\Alison\

2. 进入该目录，双击：
   Alison.exe
```

便携版不需要安装，也不需要管理员权限；删除整个目录即可完成卸载（请先确认里面没有你想保留的 `workspace/` 数据）。

## 四、方式三：源码运行

需要 Node.js 20+。

```bat
:: 在仓库根目录执行
install.cmd
start.cmd
```

- `install.cmd`：安装依赖（含 Koishi 4.18 与 ChatLuna 1.4 等第三方依赖）。
- `start.cmd`：启动 AlisonBot。

首次执行 `install.cmd` 需要联网。若公司网络需要代理，请先配置好 npm 的代理设置。

## 五、启动与验证

启动后：

1. 打开浏览器，访问 <http://127.0.0.1:5140/alison>。
2. 能看到聊天页面，说明网页平台插件已就绪。
3. 由于还没配置 API Key，**Alison 会主动开口**引导你完成配置，流程见 [03-首次部署与对话引导.md](03-首次部署与对话引导.md)。

如果想改用 QQ，需要先在配置里启用 QQ 平台插件并接好 OneBot v11 实现（如 NapCat / LLOneBot / SnowLuma），详见 [05-插件体系与多平台兼容.md](05-插件体系与多平台兼容.md)。

## 六、常用目录

```text
<工作区>/
├── alison.yml                # 主配置
├── plugins/
│   ├── alison/<名字>/         # Alison 插件（ICE 规范）
│   └── py/<框架>/<插件名>/    # 多平台 Python 插件
└── data/                     # 运行数据
```

修改 `alison.yml` 后无需重启，热更新会进程内生效，详见 [06-热更新与自治能力.md](06-热更新与自治能力.md)。

## 七、卸载

| 安装方式 | 卸载方法 |
| --- | --- |
| 安装程序 | 从「设置 → 应用」中卸载；如需彻底清理，手动删除工作区目录 |
| 便携版 | 直接删除解压目录 |
| 源码 | 删除仓库目录及其依赖目录 |

卸载前请备份工作区中你想保留的内容（配置、记忆数据等）。

## 八、常见问题

**端口 5140 被占用**
在 `workspace/alison.yml` 中把网页平台端口改成空闲端口，然后访问 `http://127.0.0.1:<新端口>/alison`。也可以直接在对话里让 Alison 帮你改。

**双击 `Alison.exe` 后窗口一闪而过**
以源码方式运行时，请在命令行里执行 `start.cmd` 以便看到报错信息；也可检查工作区目录是否可写。

**杀毒软件或防火墙提示**
这是本机自托管服务的常见提示。请允许其在本地回环地址（`127.0.0.1`）上监听；默认配置只监听本机，不对局域网开放。

**想让局域网内的设备访问网页聊天**
把网页平台监听的 host 从 `127.0.0.1` 改为 `0.0.0.0`（或指定网卡地址）并放通防火墙端口。请注意：这会把聊天界面暴露给同网段的其他设备，请自行评估风险，必要时加上访问控制。

**源码运行时提示 Node 版本过低**
升级到 Node.js 20 或更高版本后，重新执行 `install.cmd`。

**Python 插件不生效**
确认本机已安装 Python 3.9+，并且插件放在 `workspace/plugins/py/<框架>/<插件名>/` 下。兼容桥的能力边界见 [05-插件体系与多平台兼容.md](05-插件体系与多平台兼容.md)。
