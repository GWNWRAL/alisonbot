# 04 · 控制中心与系统设置

控制中心由网页平台插件 `koishi-plugin-alison-platform-web` 提供，入口与聊天页一致：

```text
http://127.0.0.1:5140/alison
```

只要网页平台插件处于启用状态，控制中心就可用；即使你没接 QQ，也能在这里完成绝大部分管理工作。

## 一、面板总览

| 面板 | 用途 | 常见操作 |
| --- | --- | --- |
| 聊天 | 与 Alison 对话 | 聊天、让她改配置、让她装插件 |
| 用量 | 查看调用与开销情况 | 观察消耗，判断是否需要调整模型 |
| 记忆 | 查看与管理她记住的内容 | 检查、清理记忆条目 |
| 插件 | 管理插件 | 查看、启用、禁用、安装插件 |
| 系统设置 | 配置模型、平台与能力开关 | 改端口、换模型、开关能力 |

> 各面板的具体字段与布局以实际界面为准。本文描述的是各面板的职责与典型操作。

## 二、聊天

聊天页与 QQ 私聊是同一套对话能力的两个入口：对话拦截器链、人设、记忆等对两者一致。

在聊天里可以直接下达管理指令，例如：

- 「把回复长度限制调短一点」→ 她改配置并热生效；
- 「给我加个搜图能力」→ 她安装并启用对应插件；
- 「检查一下 QQ 为什么连不上」→ 她做自检并尝试修复。

这些能力的前提是启用了自治插件 `koishi-plugin-alison-autonomy`，边界见 [06-热更新与自治能力.md](06-热更新与自治能力.md)。

## 三、用量

用量面板用于观察调用情况与开销，典型关注点：

- 近期调用量与趋势，判断是否异常增长；
- 按模型区分消耗，决定是否切换到更经济的模型；
- 结合记忆与上下文长度，排查「为什么变贵了」。

## 四、记忆

记忆面板用于查看与管理 Alison 记住的内容。

- 她记住的内容应当是**你希望她记住的**；不符合预期时，在这里清理；
- 记忆属于可关闭的能力：关闭后不再使用，相关开关在系统设置里；
- 记忆的数据保存在工作区的数据目录中。具体存储格式与字段属于实现细节，以仓库为准。

## 五、插件

插件面板是「一切皆插件」的落地入口：

| 操作 | 说明 |
| --- | --- |
| 查看 | 列出当前已安装的插件与启用状态 |
| 启用 / 禁用 | 进程内生效，无需重启 |
| 安装 | 安装新插件；也可让 Alison 在对话里帮你装 |

插件类型与兼容性见 [05-插件体系与多平台兼容.md](05-插件体系与多平台兼容.md)：

- Alison 插件（ICE 规范）放在 `workspace/plugins/alison/<名字>/`；
- 多平台 Python 插件放在 `workspace/plugins/py/<框架>/<插件名>/`；
- Koishi 生态插件与 ChatLuna 模型适配器按 Koishi 的方式管理；
- MCP 工具经 `koishi-plugin-chatluna-mcp-client` 接入。

## 六、系统设置

系统设置覆盖三类内容：

**模型**

| 项 | 说明 |
| --- | --- |
| 提供方 | deepseek / qwen / 任意 OpenAI 兼容网关 |
| API Key | 存储在本机配置中；界面上不要截图外发 |
| baseURL | 自建或第三方兼容网关的地址 |

**平台**

| 项 | 说明 |
| --- | --- |
| 网页 | 启用状态、监听地址与端口（默认 `127.0.0.1:5140`） |
| QQ | 启用状态、OneBot v11 连接方式与地址 |

**能力**

| 项 | 说明 |
| --- | --- |
| 记忆 | 是否记住对话中的信息 |
| 日记 | 是否记录日记类内容 |
| 好感度 | 是否启用好感度机制 |

## 七、设置怎么生效

在控制中心改设置、在对话里让 Alison 改、直接编辑 `workspace/alison.yml`——三种方式效果一致：

- 常见改动**进程内直接生效，不重启**；
- 插件启用/禁用、安装新插件同样不需要重启；
- 少数需要整体重建的改动（例如 ChatLuna 预设的会话级缓存）会提示重启。

完整边界见 [06-热更新与自治能力.md](06-热更新与自治能力.md)。

## 八、安全建议

- 控制中心默认只监听 `127.0.0.1`，即仅本机可访问。若改为对局域网开放，请自行评估风险。
- 不要把包含 API Key 的界面截图公开。
- 修改配置前建议先备份 `workspace/alison.yml`。
